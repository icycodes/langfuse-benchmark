# Create a Chat Prompt with Message Placeholders (Langfuse Python SDK) ## Background https://langfuse.com/ is an open-source LLM engineering platform. Its prompt management product supports an advanced feature called **message placeholders** that allow you to insert a list of chat messages at specific positions within a chat prompt. The placeholders are resolved at runtime via the `compile()` method, so you can dynamically inject conversation history or few-shot examples while keeping the rest of the prompt versioned in Langfuse. Your job is to write a small Python script that uses the Langfuse Python SDK to create such a chat prompt in your Langfuse project, then compiles it at runtime with a real chat history list, and saves both the runtime-compiled prompt and the remote prompt ID to a log file. ## Requirements * Use the Langfuse Python SDK (`pip install langfuse`). * Read the Langfuse credentials and base URL from the environment variables `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, and `LANGFUSE_BASE_URL`. * Read the per-trial isolation id from the `ZEALT_RUN_ID` environment variable. * Use the Langfuse Python SDK to create a **chat** prompt whose name is `movie-critic-chat-${run-id}` (substitute the actual value of `ZEALT_RUN_ID`). * The chat prompt's `prompt` payload must contain exactly three entries, in this order: 1. A `system` message with content `You are an {{criticlevel}} movie critic`. 2. A message placeholder named `chat_history`. 3. A `user` message with content `What should I watch next?`. * The prompt must be created with the label `production`. * After creation, fetch the prompt back from Langfuse (using the SDK) and compile it with: * the variable `criticlevel="expert"`, and * the placeholder `chat_history` resolved to the following two messages (in this order): * `{"role": "user", "content": "I love Ron Fricke movies like Baraka"}` * `{"role": "user", "content": "Also, the Korean movie Memories of a Murderer"}`. * Save the result to `/home/user/myproject/output.log` (see Acceptance Criteria for the exact format). * Make sure pending events are flushed before the script exits. ## Implementation Hints * Use `from langfuse import get_client` and `langfuse = get_client()` to instantiate the SDK.
